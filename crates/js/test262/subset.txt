# The test262 subset of the JavaScript spike (ADR 0026 section 13).
#
# `feature NAME`: tests with a `features` entry outside this list are
#   skipped (tests without features always run).
# `dir PATH`: a group of tests (the first four components of the directory,
#   relative to the test262 directory) that `just test262` runs.
#
# Tests are also skipped when they include a harness file other than
# assert.js, sta.js, propertyHelper.js, compareArray.js, isConstructor.js,
# fnGlobalObject.js, nans.js, decimalToHexString.js, nativeErrors.js,
# asyncHelpers.js, promiseHelper.js, regExpUtils.js, compareIterator.js
# or proxyTrapsHelper.js, or have the flags module or
# CanBlockIsTrue, or use $262.createRealm, $262.agent or
# $262.detachArrayBuffer. Tests with the flag async get doneprintHandle.js
# and pass when they print Test262:AsyncTestComplete.
